# Generic Astro + Cloudflare + Supabase composition example

This is a compile-only scaffold showing how a future Astro frontend could compose the framework-neutral core with Cloudflare runtime contracts and PostgreSQL/Supabase persistence adapters.

It intentionally contains no Astro dependency, production URL, Supabase project identifier, credential, private course content, booking data, or learner data. Integration packages will be added only after their contracts are designed and tested.
